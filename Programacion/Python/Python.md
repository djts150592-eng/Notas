# Python
Python es uno de los lenguajes de programación más populares, versátiles y utilizados del mundo. A diferencia de C o C++, que se enfocan en el control estricto del hardware, Python fue diseñado con una filosofía muy clara: **la legibilidad y la simplicidad**.

Su creador, Guido van Rossum (quien lo lanzó en 1991), quería un lenguaje que fuera tan fácil de leer como el inglés, reduciendo las líneas de código necesarias para hacer una tarea.

---
## ¿Por qué es tan famoso y querido?
- **Sintaxis limpia y amigable:** No usa puntos y comas (`;`) al final de las líneas ni llaves (`{}`) para agrupar el código. Utiliza espacios en blanco (indentación), lo que obliga a que el código se vea limpio y ordenado por defecto.
- **Es un lenguaje de alto nivel:** No tienes que preocuparte por gestionar la memoria RAM de tu computadora de forma manual (como en C); Python se encarga de todo eso en segundo plano.
- **Es multipropósito:** No está limitado a un solo campo. Sirve tanto para crear una página web como para programar un robot o analizar datos financieros.
- **Comunidad gigantesca:** Al ser tan usado, existen miles de librerías gratuitas (herramientas prefabricadas) que te permiten añadir funciones complejas a tu programa con una sola línea de código.
# ¿Para qué se usa en el mundo real?
Python es el rey absoluto en las tecnologías del futuro:

1. **Inteligencia Artificial y Ciencia de Datos:** Es el estándar de la industria para entrenar modelos de IA, redes neuronales y analizar grandes volúmenes de datos (herramientas como ChatGPT, algoritmos de Netflix y la NASA lo usan).
2. **Desarrollo Web:** Se usa en el lado del servidor (backend) para hacer funcionar plataformas gigantescas como Instagram, Spotify y Pinterest.
3. **Automatización (Scripts):** Es ideal para crear pequeños programas que hacen tareas repetitivas por ti, como renombrar miles de archivos en tu computadora, descargar datos de internet automáticamente o enviar correos programados
---
## Una comparación rápida
Para que veas la diferencia de simplicidad, mira cómo se escribe el clásico mensaje de **"Hola Mundo"** en C++ frente a Python:

### En C++:

``` C++
#include <iostream>
int main() {
    std::cout << "Hola Mundo";
    return 0;
}
```

### En Python:

```Python
print("Hola Mundo")
```
