# Java
## ¿Que es Java?
Java es un lenguaje de programación de alto nivel, orientado a objetos, seguro y de propósito general que se utiliza para desarrollar aplicaciones de todo tipo. Fue creado por Sun Microsystems (ahora propiedad de Oracle) en 1995 y su principal filosofía es "Escribe una vez, ejecútalo en cualquier lugar" (WORA, por sus siglas en inglés)
## Características
- **Multiplataforma:** El código de Java no se compila directamente para un sistema operativo específico, sino que se transforma en un código intermedio llamado _bytecode_. Este corre sobre la **JVM (Máquina Virtual de Java)**, lo que significa que el mismo programa funciona en Windows, Mac o Linux sin cambios.
- **Orientado a objetos:** Todo en Java se organiza en base a "objetos" y "clases", lo que ayuda a escribir código ordenado, reutilizable y fácil de mantener en proyectos grandes.
- **Gestión automática de memoria:** Cuenta con un _Garbage Collector_ (recolector de basura) que libera automáticamente la memoria de la computadora que el programa ya no está usando, evitando errores comunes de rendimiento.
- **Tipado estricto:** Te obliga a definir qué tipo de datos estás usando (números, texto, etc.) desde el principio, lo que reduce drásticamente la cantidad de errores al programar.
## Principales usos
Java está en todas partes, desde tu teléfono hasta servidores empresariales:
- **Aplicaciones Android:** El sistema operativo móvil y muchas de sus apps nativas están construidas con Java.
- **Sistemas empresariales y bancarios:** Es el rey en el _backend_ de grandes empresas y bancos debido a su alta seguridad y estabilidad.
- **Videojuegos:** El caso más famoso del mundo hecho en Java es la versión original de _Minecraft_.
- **Herramientas de Big Data:** Tecnologías de análisis de datos masivos como Apache Hadoop y Spark se apoyan fuertemente en Java.
