# Ciclos o Bucles
Los ciclos o bucles en java son estructuras de control que nos permiten repetir un bloque de código varias veces de forma automática.
Java ofrece cuatro estructuras principales de repeticion:
1. Ciclo [[for]]
2. Ciclo [[while]]
3. Ciclo [[do-while]]
4. Ciclo [[for-each]]

# Notas
* En realidad uno puede hacer el mismo trabajo con cualquiera de los ciclos, la única diferencia es que algún ciclo se adapta mejor a nuestras necesidades y no necesitamos hacer arreglos forzados.
