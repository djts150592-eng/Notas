# do-while
Ejecuta el bloque de código **al menos una vez** y luego evalúa la condición al final.
## Sintaxis 
```java
do {
    // Instrucciones a repetir
} while (condición);

```
## Ejemplos
```Java
int i = o;
do {
    System.out.println("Número: " + i);
    i++;
} while (i <= 5);
// Salida esperada
	//Numero: 0
	//Numero: 1
	//Numero: 2
	//Numero: 3
	//Numero: 4
	//Numero: 5
```

En el ejemplo anterior se utiliza el ciclo for para hacer un conteo del 0 al 5 he imprimir cada aumento en pantalla
